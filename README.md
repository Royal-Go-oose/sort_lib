# sort_lib
Библиотека сортировок на чистом C++ без стандартной библиотеки.

## Алгоритмы

- `bubble_sort`
- `insertion_sort`
- `selection_sort`
- `quick_sort`
- `merge_sort`

## Использование

```cpp
#include "sortlib.hpp"

int arr[] = {5, 3, 1, 4, 2};
sortlib::quick_sort(arr, arr + 5);                                     // по возрастанию
sortlib::merge_sort(arr, arr + 5, [](const int& a, const int& b){      // по убыванию
    return a > b;
});
```
